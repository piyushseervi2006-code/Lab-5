# My College Web Page

## Aim

Create an HTML page for a college with the college name, address, courses offered, background image, and scrolling text for upcoming events.

## Description

This webpage displays information about **JAIN UNIVERSITY**. It includes the college address, courses offered, a background image, and scrolling information about upcoming examinations and events.

## College Details

**JAIN UNIVERSITY**

District Fund Road, Jayanagar 9th Block,  
Bengaluru, Karnataka, India

## Courses Offered

- B.Tech in Computer Science
- B.Com in Accounting & Finance
- B.Sc in Mathematics
- MBA in Business Administration

## Upcoming Events

- Upcoming Exams start from 25th September
- Annual Sports Day on 15th October
- Cultural Fest on 20th November

## Technologies Used

- HTML
- CSS

## Features

- College name displayed in large text
- College address displayed below the name
- Background image added to the webpage
- Courses displayed in different colors, styles, and typefaces
- Scrolling text for upcoming exams and events

## Files

- `mycollege.html` - Main college webpage
- `college.jpg` - Background image

## How to Run

1. Download or clone this repository.
2. Make sure `mycollege.html` and `college.jpg` are in the same folder.
3. Open `mycollege.html` in a web browser.

## Conclusion

The webpage successfully displays the college information with different text styles, a background image, and scrolling event information using HTML and CSS.
